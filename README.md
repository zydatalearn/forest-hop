# Forest Hop · 森林跃跃

适合移动端的 HTML5 纵向跳跃小游戏。建议 GitHub 仓库名：forest-hop。

## 运行
双击 index.html 即可运行，也可使用 VS Code Live Server。
部署 GitHub Pages 时选择仓库根目录，无需构建。

## 操作
- 手机：按住画面左侧或右侧移动；单指滑过中线换向，松手停止。
- 电脑：方向键或 A / D；结束后空格重开。
- 下落时踩中黄色弹簧可获得约 3.5 倍普通跳跃高度。
- 有裂纹的木板只能踩一次：弹起后断裂、掉落并消失。
- 画面左右边缘可以穿越。

## 难度
- 按路线高度逐步增加难度，普通木板间距从 50 增至 68 像素，约 300 分后不再增加。
- 约 120 分后的路线开始出现弹簧大跨度，必须踩中黄色弹簧才能到达上方木板。
- 必踩弹簧及其下一块木板不会断裂，横向距离按跳跃时间限制，不要求穿越屏幕边缘。
- 松果 +10 分，钻石 +30 分，每件道具只计一次。
- 约 180 分后出现炸弹与荆棘，碰到会结束游戏；生成时避开相邻木板之间的可达路线，保留安全通道。
- 实际得分达到 2000 后，新生成的木板可能横向移动；速度从 12 像素/秒逐渐增加，4000 分达到 36 像素/秒上限，往返幅度 18 像素。重开恢复初始难度。
- 运行 `node tests/platform-route.cjs` 可验证随机路线在实际物理和碰撞逻辑下可达。

## 结构
- index.html：页面入口
- src/game.js：控制、物理和绘制
- src/style.css：移动端布局
- assets/images/：实际使用的图片

## 来源
基于 https://github.com/ImKennyYip/doodle-jump 改进。
松鼠角色的 8 帧动作、森林、平台和弹簧由 AI 生成。
发布前请自行确认原项目及角色素材的使用授权。

## 排行榜
本机前 3 名保存在当前浏览器 localStorage，游戏结束时记录昵称和分数。旧分数记录仍可读取。
首次进入需设置昵称，确认后在当前浏览器锁定，清除浏览器数据会重置。
游戏结束后可选择是否上传本次名称和分数，上传前没有分数编辑入口；选择否仍保留本机成绩。
联机前 10 名由 CloudBase 云函数读取 PostgreSQL，同名玩家只保留最高分；即使未进入前十，也显示本人的名次和最高分；上传失败可重试。
昵称仅在当前浏览器锁定，不同浏览器使用同名会合并排名；客户端分数未经服务端游戏验证。

## CloudBase
环境：forest-hop-d2g5ydn2ydb209f8a（上海）。HTTP 云函数 forest-hop-api 使用 Nodejs18.15，监听 9000 端口。
网关 /forest-hop-api 剥掉路径前缀，GET /scores 读取排行，POST /scores 上传，GET /health 检查服务。
服务端通过 CloudBase PostgreSQL 官方 REST API 读写，数据库只授予 service_role 权限；SQL RPC 原子更新最高分。
环境变量 TCB_ENV、CLOUDBASE_APIKEY、ALLOWED_ORIGIN 由云端配置，密钥不得提交到仓库或浏览器。服务密钥由仓库维护者在 CloudBase 控制台负责轮换或撤销。
数据库结构记录在 cloudbase/migrations/，云函数源码位于 cloudfunctions/forest-hop-api/。
运行 `node tests/cloudbase-api.cjs` 验证接口校验、CORS 和错误处理。

## 角色与移动端
角色使用 squirrel-jump-sheet.webp 的 8 帧动作，根据跳跃阶段切换，向左移动时镜像；碰撞尺寸保持不变。
所有图片使用 WebP，进入游戏前等待下载与解码完成；加载失败可重试。画布按显示尺寸和设备像素密度绘制，避免高密度屏幕放大低分辨率画布。
昵称、排行和分数位于画布上方的独立栏，避免遮挡木板与角色。

## 新素材
钻石、松果、炸弹由内置 imagegen 生成：单个透明背景道具、电影级 CG、清晰材质与轮廓。背景提示词：暖色森林、奶油金色薄雾、柔和琥珀光、边缘稀疏树干、中央留白且低对比，无地面、文字或枝叶遮挡。素材均转换为高质量 WebP，保留道具透明通道和原始分辨率；背景以极慢视差滚动。
